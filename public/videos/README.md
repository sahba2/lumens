# پیش‌نمایش ویدیوی دوره‌ها

فایل‌های ویدیوی معرفی/پیش‌نمایش هر دوره را در همین پوشه قرار دهید و مسیر آن را در
`lib/data.ts` روی فیلد `videoUrl` همان دوره بنویسید:

```ts
videoUrl: "/videos/c-09-preview.mp4",
```

- نام فایل توصیه‌شده: `c-XX-preview.mp4` (همان `id` دوره).
- فرمت پیشنهادی: MP4 / H.264، رزولوشن ۱۲۸۰×۷۲۰ یا ۱۹۲۰×۱۰۸۰، حجم کمتر از ۱۵ مگابایت
  (این ویدیو در مرورگر باز می‌شود و روی موبایل هم باید سریع لود شود).
- استفاده از لینک بیرونی هم مجاز است؛ کافی است آدرس کامل را بگذارید:
  `videoUrl: "https://www.aparat.com/v/xxxxxxxx"` یا لینک یوتیوب.

اگر `videoUrl` خالی/حذف شود، دکمهٔ «تماشای پیش‌نمایش دوره» در مودال دوره نمایش
داده نمی‌شود و بقیهٔ صفحه بدون تغییر کار می‌کند.
